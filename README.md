# MBSP Fleet Command Center

Sistem web untuk memantau pembaikan kenderaan, ketersediaan kompaktor standby di 7 depoh dan prestasi bengkel panel Majlis Bandaraya Seberang Perai.

## Versi GitHub Pages

Laman ini berjalan sepenuhnya di dalam browser (mod tempatan):

- Data disimpan dalam browser setiap pengguna sahaja. Tiada data dikongsi antara pengguna atau komputer.
- Hanya akaun **Pentadbir** tersedia. Log masuk pertama: `admin` / `admin123`, kemudian anda wajib menukar kata laluan.
- Akaun Panel Bengkel dan PIC Depoh, serta data pusat, memerlukan pelayan.
